# 🧬 Intelligent Skin Cancer Detection Using Hybrid Deep Learning and Machine Learning

## 📌 Project Overview
This project focuses on detecting skin cancer using a hybrid Deep Learning and Machine Learning approach. It combines MobileNetV2 for feature extraction and Support Vector Machine (SVM) for classification.

The system analyzes dermoscopic skin images and predicts the corresponding skin lesion category.

## 🎯 Objectives
- Develop an intelligent skin lesion classification system.
- Extract image features using MobileNetV2.
- Classify extracted features using SVM.
- Provide an easy-to-use interface using Gradio.

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- MobileNetV2
- Support Vector Machine (SVM)
- Scikit-learn
- NumPy
- Pandas
- Google Colab
- Gradio

## 📂 Dataset
**HAM10000 Dataset**

A publicly available dermoscopic image dataset used for skin lesion research.

## ⚙️ Methodology
1. Image preprocessing and resizing (224 × 224).
2. Feature extraction using MobileNetV2.
3. Classification using Support Vector Machine.
4. Prediction through a Gradio web interface.

## 💻 Implementation
The project was developed using Google Colab.

## ⚠️ Disclaimer
This project is developed for academic and research purposes only. It is not intended to replace professional medical diagnosis.
